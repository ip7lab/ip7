# IP7 — IP 检测站修改版源码

本站 https://ip7.de5.net 基于开源项目 MyIP 构建，遵循 AGPL-3.0 协议。

## 上游与部署版本

- 上游项目：jason5ng32/MyIP（https://github.com/jason5ng32/MyIP）
- 上游许可证：AGPL-3.0（本仓库沿用 AGPL-3.0，LICENSE 与版权声明保留原样）
- 线上部署版本：以本仓库 main 构建（上游 MyIP 主线＋本站修改），构建提交 6193436（2026-11-02）；2026-11-01 曾以官方镜像 v8.0.0 部署，2026-11-02 已切换为源码构建
- 线上部署方式：从本仓库源码以仓库自带 Dockerfile 构建 Docker 镜像（node:24-alpine 内构建，pnpm 构建前端），容器仅绑回环端口（当前前端 18968、后端 11968），经 OpenResty 反代对外提供 HTTPS 服务；当前镜像 ip7-source:20261102
- 本仓库由上游公开仓库导入，完整保留上游源码与历史；下述修改点均在源码内生效（构建进镜像），反代层仅保留场景页/隐私页静态路由与首页底部品牌横条注入

## 本站修改点（相对上游）

1. 品牌替换（源码内）：页眉与页脚字标改为 IP7；启动加载动画与页眉/页脚头像共用的原作者黑客 SVG（Brand.vue）改为定位针 PNG（/ip7-icons/，图标包见 public/ip7-icons/），加载动画为图形脉冲、无人物形象；页面标题与 manifest 改为 IP7。
2. 页脚与来源（源码内）：页脚来源改为如实口径「本站基于开源项目 MyIP（IPCheck.ing）」，链接指向上游；许可证为 AGPL-3.0；首页底部另有反代注入的品牌横条，含四个场景页入口、隐私页入口、联盟返佣披露与诚实口径说明，并加「源代码」链接（指向本仓库）与一行 AGPL-3.0 声明。
3. 场景层：新增四个静态场景页（跨境电商注册、AI 工具、金融与加密账户、境外电话办理），含清单、结果解读、诚实口径与返佣披露；新增隐私政策页，承诺大陆用户 IP 在境外悉尼机解析、默认不把原始 IP 发给第三方 API。
4. 文案调整（源码内）：城市字段旁标注数据来源并注明「城市级定位仅供参考」；IPv6 探针无结果时显示正常口径文案「未检测到 IPv6：当前网络未提供 IPv6，属正常情况」，不用报错样式；连通性测试区提示「开关代理后请刷新页面重新测试，本结果不会自动更新」。
5. 站内 GitHub 入口：页眉星标、页脚 GitHub 图标指向本仓库（https://github.com/ip7lab/ip7），星数取自本仓库；页脚署名链接仍指向上游（见第 2 条）。
6. 部署配置：OpenResty 反代配置（80/443、ACME 与 ZeroSSL 验证路径、场景页与隐私页静态路由）与上述静态页，见本仓库 ip7-overlay/ 目录说明。

## 密钥与隐私

本仓库不含任何密钥凭据：MaxMind 密钥、环境变量、证书私钥一律不在仓库内；本地配置以 `.env.example` 占位。线上反代与证书文件仅存于部署服务器，不进本仓库。
