隐私政策

承诺：大陆用户 IP 在境外悉尼机解析、存多久、发给谁；默认不把原始 IP 发给第三方 API。

本站部署在境外悉尼服务器上。你访问本站时，你的 IP 会在该服务器上被解析，用于展示归属地、ASN 等检测结果。

  • 日志只做聚合计数（如日访问量、结果页推荐点击率），不用于追踪个人。
  • 原始 IP 限期删除或哈希处理，报告链接不带 IP。
  • 默认不把原始 IP 发给第三方 API；检测结果中标注数据源与置信度的项目，均为聚合或公开数据口径。
  • 本站不收集、不询问你在各平台的账号、密码、钱包、电话号码。
  • 本站不提供绕过平台规则、KYC、制裁限制的指导。

如你对以上承诺有疑问，请通过本站首页的联系方式反馈；政策变更时会在本页更新。
