跨境电商注册：IP 检查清单

适用：要在境外电商平台注册店铺、收款账号的用户。先在首页测出当前 IP，再按下面逐项对照。

1. 归属地与平台要求是否一致

看首页的国家/地区、ASN 归属。注册地与 IP 归属地不一致，是最常见的触发人工审核原因之一。

2. 是否为住宅 / 代理 / 机房 IP

本站判断为 ASN 启发式 + 公开名单推测，页面会标注置信度与来源，不对“纯净度”下断言。机房 IP 被平台识别的概率通常高于住宅 IP，但这只是推测，不是平台规则原文。

3. DNS 与 WebRTC 是否泄漏

首页的 DNS 泄漏、WebRTC 泄漏两项若显示真实本地 IP，说明代理没有完全接管流量，注册时应先修复再提交。

4. IPv6 是否泄漏

若你本地有 IPv6 出口，首页会显示 IPv6 地址；若显示“无 IPv6 出口”，这是正常结果，不是检测失败。

5. 指纹一致性

浏览器语言、时区应与 IP 归属地大体一致；明显不一致（如 IP 在悉尼、时区却在北京）也可能引起注意。无数据源的指标本站标注“无法检测”，不编造结果。
